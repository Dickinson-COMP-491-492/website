# RD04 - Professional Ethics

## Preparation

Review the expectations for preparation for the [Readings and Class Discussions](./RD-ReadingsAndDiscussion.md).

## Assigned Readings

1. Read Part 8 (pg. 32) in "[An Introduction to Software Engineering Ethics](https://www.scu.edu/media/ethics-center/technology-ethics/Students.pdf)" by Shannon Vallor and Arvind Narayanan for the [Markkula Center for Applied Ethics](https://www.scu.edu/ethics/) at Santa Clara University.
2. Read the [ACM Code of Ethics and Professional Conduct](https://www.acm.org/code-of-ethics).
3. Read the [Automated Active Response Weaponry](https://www.acm.org/code-of-ethics/case-studies/automated-active-response-weaponry) case study and the following analysis of the scenario to get a feel for how the ACM Code of Ethics can be applied.
4. Read the [Malicious Inputs to Content Filters](https://www.acm.org/code-of-ethics/case-studies/malicious-inputs-to-content-filters) case study and the following analysis of the scenario to get a feel for how the ACM Code of Ethics can be applied.
5. Read the [George and the Jet](./RD04-GeorgeAndTheJet.md) case study.

## Discussion Questions

1. Which of the qualities of a _superprofessional_ do you think you exhibit most strongly? Which would you hope to become better at? Why?
2. Based on your reading of the ACM Code of Ethics and the two case studies, identify 3 or 4 clauses from the ACM Code of Ethics about which you have a question. Your questions might be about the meaning of the clause, about how the clause was used in the analysis of one of the case studies, or a concern about applying it in real life. Prepare to state and explain your question and connect it to the case study as appropriate.
3. Which clauses from the ACM Code of Ethics are most relevant to an analysis of the George and the Jet case study and why?
4. Based on the ACM Code of Ethics, what should George do? What would you do? Why?
